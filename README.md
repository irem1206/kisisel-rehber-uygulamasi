# kisisel-rehber-uygulamasi
C# dili ve Windows Forms ara yüzü kullanılarak geliştirilmiş kişisel rehber uygulamasıdır. Kullanıcıların ad, soy ad, telefon ve e posta bilgileri XML formatı olarak kaydedilmekte ve okunabilmektedir. Veriler XML dosyası ile kalıcı hale getirilmiştir. Ara yüz tasarımı ve veri yönetimi Visual Studio ortamında gerçekleştirilmiştir.
